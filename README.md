# Password Manager

A simple and secure password manager application built using Python's Tkinter library. The application allows users to securely store and retrieve passwords for various services. Passwords are stored in-memory (not in a database) for simplicity.

## Features
- **Add Password**: Add a new password for a service with username and password details.
- **Get Password**: Retrieve the stored username and password for a service.
- **User Interface**: A user-friendly interface using Tkinter for ease of use.
